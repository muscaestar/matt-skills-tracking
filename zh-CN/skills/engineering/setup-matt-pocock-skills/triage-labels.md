# Triage 标签

这些技能以五个标准 triage 角色的术语进行交流。本文件把这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                                  |
| -------------------------- | ------------------ | ------------------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估这个 issue              |
| `needs-info`               | `needs-info`       | 等待报告者提供更多信息                |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整，可以交给 AFK agent          |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现                          |
| `wontfix`                  | `wontfix`          | 不会被处理                            |

当技能提到某个角色时（例如"应用 AFK-ready triage 标签"），使用本表中对应的标签字符串。

编辑右列以匹配你实际使用的词汇。
